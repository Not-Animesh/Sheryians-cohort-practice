01

What is OOP?

OOP stands for Object-Oriented Programming . Instead of writing all your code randomly, you group related data and functions together inside objects.

Real-world example

A Car

Data → brand, color, speed

Actions → start(), brake(), accelerate()

Simple mental model

Object = Data + Actions 

const car = {

  brand: "Toyota",

  color: "Black",

  speed: 0,

  start() {

    console.log("Car started");

  }

};

This is already object-oriented thinking.

03

Class

A class is like a blueprint . Imagine you want to create 100 students. You don't want to manually write the same object structure 100 times. A class lets you create objects using one blueprint.

Think about a building.

Class = Building Blueprint

Object = Actual Building

    this.age = age;

}

  new Student("Animesh", 20);

05

What is "this"?

Inside a class, the keyword this refers to the current object . 

class Student {

  constructor(name) {

    this.name = name;

  }


  introduce() {

    console.log(
      "My name is " + this.name
    );

  }

}

Think of it like this

student1 → this = student1
student2 → this = student2

The same class can create many objects, and each object gets its own data.

07

Encapsulation

Encapsulation means keeping data and the functions that work with that data together. It can also mean protecting internal data from being changed directly. 

class BankAccount {

  #balance = 0;


  deposit(amount) {

    if (amount > 0) {

      this.#balance += amount;

    }

  }


  getBalance() {

    return this.#balance;

  }

}

Why?

The # makes the property private. Code outside the class cannot directly access it. 

const account =
  new BankAccount();


account.deposit(500);


console.log(
  account.getBalance()
);

// 500

09

super()

When a child class has its own constructor, super() is used to call the parent constructor. 

class Animal {

  constructor(name) {

    this.name = name;

  }

}


class Dog extends Animal {

  constructor(name, breed) {

    super(name);

    this.breed = breed;

  }

}


const dog =
  new Dog("Bruno", "Labrador");


console.log(dog.name);

console.log(dog.breed);

10

Polymorphism

The word sounds complicated. But the basic idea is simple: different objects can respond to the same method in different ways. 

class Animal {

  speak() {

    console.log("Animal sound");

  }

}


class Dog extends Animal {

  speak() {

    console.log("Woof!");

  }

}


class Cat extends Animal {

  speak() {

    console.log("Meow!");

  }

}

Same method, different behavior 

const dog = new Dog();

const cat = new Cat();


dog.speak();

// Woof!


cat.speak();

// Meow!

Both objects have speak() , but each behaves differently.

12

Getters

A getter lets us access a method like a normal property. 

class Rectangle {

  constructor(width, height) {

    this.width = width;

    this.height = height;

  }


  get area() {

    return this.width * this.height;

  }

}


const rectangle =
  new Rectangle(10, 5);


console.log(
  rectangle.area
);

13

Setters

A setter lets us control what happens when a property is changed. 

class User {

  constructor(name) {

    this.name = name;

  }


  get username() {

    return this.name;

  }


  set username(newName) {

    if (newName.length >= 3) {

      this.name = newName;

    }

  }

}

16

Closure

A closure happens when an inner function remembers variables from the outer function even after the outer function has finished running. 

function createCounter() {

  let count = 0;


  return function () {

    count++;

    console.log(count);

  };

}


const counter =
  createCounter();


counter();

counter();

counter();
Important:

The returned function remembers the private count variable. This idea is extremely useful for factory functions and module patterns.

17

IIFE + Module Pattern

IIFE stands for Immediately Invoked Function Expression . The function runs immediately after it is created. It is often used to create a private scope. 

const Bank = (function () {

  let BankBalance = 12000;


  function checkBalance() {

    console.log(
      `Your Bank Balance is ${BankBalance}`
    );

  }


  function setBalance(amount) {

    BankBalance = amount;

  }


  function withdraw(amount) {

    if (amount > BankBalance) {

      console.log(
        "Insufficient Balance"
      );

    } else {

      BankBalance -= amount;

      console.log(
        `You withdrew ${amount}`
      );

    }

  }


  return {

    checkBalance,

    setBalance,

    withdraw

  };

})();

Public:

Bank.checkBalance()

Bank.withdraw()

Bank.setBalance()

Private:

Bank.BankBalance

The balance is protected by the closure.

19

Factory + Private Data

Factory functions can also use closures to create private variables. 

function createBankAccount(
  owner,
  initialBalance
) {

  let balance =
    initialBalance;


  function deposit(amount) {

    balance += amount;

  }


  function checkBalance() {

    console.log(
      `${owner}: ₹${balance}`
    );

  }


  return {

    deposit,

    checkBalance

  };

}

Each object gets private data

20

Observer Pattern

The Observer Pattern means: "Tell me when something changes." One object keeps a list of observers. When something happens, it notifies all of them.

Subject

YouTube

→

Notify

New Video

→

Observers

Subscribers 

function createYouTubeChannel(name) {

  let subscribers = [];


  function subscribe(callback) {

    subscribers.push(callback);

  }


  function uploadVideo(video) {

    console.log(
      `${name} uploaded: ${video}`
    );


    subscribers.forEach(
      function (subscriber) {

        subscriber(video);

      }
    );

  }


  return {

    subscribe,

    uploadVideo

  };

}

The channel doesn't need to know what each subscriber will do.

It only says: "Something happened."

21

Observer with Subscribe / Unsubscribe 

function createNewsAgency() {

  let observers = [];


  function subscribe(observer) {

    observers.push(observer);

  }


  function unsubscribe(observer) {

    observers =
      observers.filter(
        item => item !== observer
      );

  }


  function publishNews(news) {

    observers.forEach(
      observer => observer(news)
    );

  }


  return {

    subscribe,

    unsubscribe,

    publishNews

  };

}

How it works

1. Observer subscribes.
2. Subject stores the observer.
3. Something changes.
4. Subject notifies observers.
5. Observer reacts.

22

Factory + Observer Together

These patterns are often useful together. A factory can create a store, while the observer pattern lets other parts of the application react when the store changes. 

function createStore() {

  let state = 0;

  let observers = [];


  function subscribe(callback) {

    observers.push(callback);

  }


  function setState(newState) {

    state = newState;


    observers.forEach(
      observer => observer(state)
    );

  }


  function getState() {

    return state;

  }


  return {

    subscribe,

    setState,

    getState

  };

}

This basic idea is related to how many state-management systems work.
